# Contributing

Thanks for contributing to Adextract MCP documentation and metadata.

## Scope

This repository focuses on:

- endpoint documentation
- client setup guides
- registry metadata
- operational and support documentation

## Contribution flow

1. Create a branch for your change.
2. Keep edits focused (one concern per PR).
3. Update docs with clear examples and exact URLs.
4. Run a quick review for typos and broken links.
5. Open a PR with:
   - what changed
   - why it changed
   - any follow-up items

## Writing guidelines

- Use precise, testable statements.
- Prefer short sections with concrete examples.
- Keep client config snippets copy/paste ready.
- Do not include secrets, tokens, or private keys.

## Commit message style

Use concise imperative messages, for example:

- `docs: add Claude Desktop setup example`
- `docs: clarify OAuth discovery endpoints`
- `chore: update server metadata links`
